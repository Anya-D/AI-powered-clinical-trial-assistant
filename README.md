# AI Clinical Trial Assistant

An AI-powered clinical trial assistant built to explore how AI can make complex clinical research data more accessible and actionable.

**[Try the live demo]([https://lnkd.in/gQZY5WkN](https://ai-trial-assistant.lovable.app/))**

## Overview

The goal was to build more than a chatbot. This project is an end-to-end interface that brings together natural-language querying, clinical data analysis, and study-level workflows in one place.

## Features

- **AI Query Assistant**: ask questions about the trial data in plain English instead of manually writing queries
- **Survival Analysis**: explore time-to-event outcomes and visualize clinical study results
- **SQL Workbench**: directly query the underlying trial data and inspect how the results are generated
- **Study Documents**: a centralized way to interact with study-related information
- **Data Quality**: surface potential issues and inconsistencies in the underlying data

## Key takeaway

Applying AI to healthcare isn't just about generating answers. It's about connecting AI with structured data, analytical methods, and transparent workflows so users can actually understand and investigate the results.

## Important disclaimer

The application currently uses a **synthetic clinical-trial dataset**. It is strictly a technical demonstration and is **not intended for clinical, regulatory, or submission use**.
